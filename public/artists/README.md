# Artist images — VIP Tour Defense cards

Drop one image per artist here. The filename must match the artist `id` in
`app/events.ts`. Extension can be `.jpg`, `.png`, or `.webp` — if you use
something other than `.jpg`, update that artist's `image:` path in `events.ts`.

- **Aspect:** portrait / 3:4 crops look best (e.g. ~640×800)
- **Weight:** keep under ~300 KB each (compress; these load in a grid)
- **Rights:** the site is public — use images you have the rights to use.

If an image is missing, that artist's card automatically falls back to the
accent + flag treatment, so nothing breaks while you're still sourcing images.
